# 📝 Notepad 🖥️

## ✨ What's This All About?

Welcome to **Notepad** — a lightweight Java desktop application built with AWT and Swing that allows you to create, edit, and save plain text files. It's a simple yet functional clone of a basic text editor, complete with a toolbar, file options, and checkbox controls for an enhanced editing experience.

---

## 🔎 Features

- 📁 **Open, Save, and Create** text files easily
- 🧰 **Custom Toolbar** with buttons and checkboxes for Cut, Copy, and Select actions
- 🗂️ **Supports multiple file types** including `.txt`, `.java`, `.cpp`, `.bat`, and more
- 🧾 **Text area** with real-time editing
- 📦 **Secondary toolbar window** for visual editing options
- 🤖 Built using AWT and Swing (pure Java GUI)

---

## 🛠️ Tech Stack

- **Java AWT & Swing** – For building the graphical user interface
- **JFileChooser** – For file selection dialogs
- **Java IO** – To handle file read/write operations
